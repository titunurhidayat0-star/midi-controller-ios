Layer MIDI Channel Channel untuk Voice 2 (mode Dual)
Mode Tampilan Klasik = tampilan asli. Pa5X = layout seperti Korg Pa5X/Pa4X (fungsi sama).
Upper 3 MIDI Channel Voice ke-3 (mode Dual). OFF = tidak dipakai. Samakan dengan MIDI In Channels di keyboard.
Style Control Channel Channel Program Change untuk Style Play. Di keyboard Korg set channel ini ke Control; jangan sama dengan channel Upper. (Yamaha / Roland E-A7 tidak memakai channel ini.)
Mode Keyboard Set (Upper 1-3) Aktif: transpose, octave, pitch bend, quartertone, dan nada dikirim ke Upper 1, 2, 3 (isi Layer Channel dan Upper 3 Channel sesuai MIDI In Channels keyboard). Nonaktif: hanya Upper 1.
Koneksi & Diagnosa Keyboard Status port MIDI langsung. SYNC = kirim ulang semua setelan aplikasi (voice/Performance, bend range, transpose, quartertone, mixer). Auto-sync = kirim ulang otomatis saat kabel dicolok lagi. Tes IN = cek pesan dari keyboard sampai ke aplikasi (wajib untuk Learn). Cek Keyboard = tanya identitas keyboard. Bunyi = suara & getar saat MIDI tersambung/terputus.
Monitor = tampilkan pesan MIDI keluar/masuk. Learn QT = ubah satu nada di Quarter Tone keyboard Korg, aplikasi menyalin header SysEx aslinya. Tes QT = semua nada turun 50 cent selama 4 detik.
